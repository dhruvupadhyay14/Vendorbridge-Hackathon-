## 📌 Overview

VendorBridge is an AI-powered vendor lifecycle and procurement intelligence platform built to simplify how organizations discover, onboard, evaluate, and manage vendors.

The platform centralizes vendor information, automates procurement workflows, and provides AI-generated insights that help organizations make smarter supplier decisions.

---

## 🎯 Problem Statement

Organizations often face challenges such as:

* Manual vendor onboarding processes
* Scattered vendor information
* Slow approval workflows
* Inefficient supplier evaluation
* Limited visibility into vendor performance
* Time-consuming procurement decisions

These issues increase operational overhead and reduce procurement efficiency.

---

## 💡 Our Solution

VendorBridge provides a centralized ecosystem that enables organizations to:

✅ Digitally onboard vendors

✅ Maintain a centralized vendor repository

✅ Track vendor performance

✅ Manage procurement workflows

✅ Generate AI-powered recommendations

✅ Improve procurement decision-making

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/dhruvupadhyay14/Vendorbridge-Hackathon-.git
```

### Navigate to Project

```bash
cd Vendorbridge-Hackathon-
```

### Install Dependencies

```bash
npm install
```

### Configure Environment Variables

Create a `.env` file in the root directory:

```env
VITE_SUPABASE_URL=YOUR_SUPABASE_URL
VITE_SUPABASE_ANON_KEY=YOUR_SUPABASE_KEY
VITE_GEMINI_API_KEY=YOUR_GEMINI_API_KEY
```

### Run Development Server

```bash
npm run dev
```
